# AI Skills 目录说明

Skill 补充专项操作指导。任务职责属于用户管理的 Agent Prompt，不按关键词预选 Skill，不必每轮加载。

此目录只维护注册类型，不安装业务 Skill 或初始化种子；版本化管理、文档导入与数据库关联由 `agent-management` 模块处理，不在 SkillRegistry 中查询数据库。运行时使用请求固定的绑定版本，存在请求范围时不得回退到全局注册表。

正式 Deep Agents 将已发布 Skill 及辅助 UTF-8 资料映射为只读虚拟目录，先加载简介、按需读 SKILL.md 和资料全文。资料和正文保存在同一版本，运行只用固定快照；路径和字节限制由 `agent-management/skill-resources` 强制检查，不读取宿主机文件、不解压 ZIP、不根据文本执行脚本。Skill 不是独立 Agent，不因提及工具而扩大授权。独立任务只委派给已授权成员 Agent，成员使用自己的 Skill 与能力且不继承父历史/文件。旧 `load_skill` / `run_skill` 及其隔离配置仅用于迁移参考，正式执行服务不再暴露它们；勿新增第二套专项模型循环。

已绑定且启用的 Skill 默认可自动加载；旧显式调用扩展仅作兼容元信息保留。运行协议和通用执行限制由代码与 Agent / Tool Runtime 维护。不要把完整系统提示词、工具白名单、内部上下文或凭据发送到访客响应中。
