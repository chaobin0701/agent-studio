# 外部工具管理

本模块管理版本化 HTTP 配置、加密凭证和远程 MCP 连接/工具契约；不改变 `ai/mcp/` 静态进程内插件的边界。

- 所有外部 HTTP/MCP 请求使用 network.ts 的受限传输，不能绕过 DNS/IP 检查或跟随重定向。
- 新凭证使用 SecretBox 加密，仅存引用；不要记录原文、完整请求头或未经脱敏的远端错误。
- 配置查询使用 DatabaseService 工作区作用域；远程服务、凭证和工具关联必须在当前工作区校验。
- MCP 发现完成后才能保存目录，不自动导入、发布或授权新工具；保存配置和目录用不可变版本与乐观并发检查。
- 原生契约不可被后台随意编辑，调用前检查漂移；外部服务代码不是平台可回滚的对象。
- 适配工具仍经过统一 ToolExecutionService/ToolPolicy，不能绕过审批、参数校验、预算或审计。
- 不开放任意本地命令、Sampling、资源链接自动下载或代码执行。
- 平台不实现产品、订单等业务端点，不保留应用内特权 HTTP 通道。业务服务通过普通 HTTP／远程 MCP 接入，使用显式凭证与统一网络策略；不得按工具名称、URL 或业务字段附加特殊权限、缓存或结果处理。
