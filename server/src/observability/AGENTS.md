# Execution observability

Use a private OpenTelemetry provider and explicit OpenInference spans, exported only to the explicitly configured LangSmith destination. Framework capture uses request-local, version-pinned OpenInference callbacks, sanitized before the SDK and filtered before export. Never enable ambient LangSmith/full-state capture or install process-wide hooks/providers. Framework spans are metadata-only CHAINs without Token counters; actual paid model attempts remain the authoritative LLM spans. Metadata remains allowlisted. Conversation content may be attached only through `annotateTraceContent`, only when `AGENT_STUDIO_LANGSMITH_CONTENT_ENABLED=true`, in separate `input.value` / `output.value` fields. Scrub credential-bearing keys and known credential formats, preserve Prompt/message/tool/retrieval content otherwise, and keep binary image payloads out of traces.

Tracing is disabled by default. Configuration uses AGENT_STUDIO_LANGSMITH_* only, never ambient OTEL/LANGSMITH headers or URLs. Require an explicit key and destination when enabled. Use HTTPS for remote destinations; loopback HTTP is permitted for local protocol tests. Do not follow redirects or fall back to another destination. Export asynchronously with bounded memory/time, no retries, and no effect on business results or accounting.

Local Trace, audit and model-attempt accounting remain authoritative. Ordinary views use an allowlist projection; raw local diagnostics retain their audited debug permission. External links require both the platform observability.external.read grant and the selected workspace conversations.read grant. Query through workspace scope. Only rebuild/resolve links for matching stored provider/version/destination IDs; never trust stored arbitrary URLs. Legacy Phoenix mappings are historical only.

Cloud acceptance sends only synthetic metadata with explicit test credentials; read back stored runs before claiming ingestion success. No automatic production deployment, resource publishing or deletion of existing Phoenix data. Agent/Prompt/knowledge management stays in the existing services.
